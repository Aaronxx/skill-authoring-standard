## 反模式

| 不要 | 要 |
|---|---|
| 大而全 | 一类闭环任务一个 skill |
| 碎而杂 | 合并成有边界的流程 |
| 无边界清单 | 先写“绝对不做” |
| 无评测上线 | 三指标 + 回归集 |
| 定义句放流程/迭代节 | 定义进开头 |
| 标题共享“输出/标准/格式” | 加限定词：内容验收 / 呈现格式 |
