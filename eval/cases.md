# skill-authoring-standard 评测用例

## 一、正向用例

| # | 输入 | 期望 | 判定点 |
|---|---|---|---|
| 1 | 一个六步齐全、eval 齐全的 skill 目录 | 审计 PASS | 必需项全过 |
| 2 | 只有指令、没有边界的 skill | 审计 FAIL，提示缺边界清单 | 边界门 |
| 3 | description 无“不适用于” | 审计 FAIL | 路由门 |
| 4 | 两个章节名为“输出标准/输出格式” | 审计 WARN 标题撞词 | 编辑门 |
| 5 | 缺 eval/cases.md | 审计 FAIL | 评测门 |
| 6 | 缺 version/last_updated | 审计 FAIL | 迭代门 |

## 二、反向用例

| # | 输入 | 期望 |
|---|---|---|

| 8 | 一篇要整理的长文 | 转 knowledge-router |
| 9 | 只要一段 prompt | 不封装成 skill |
